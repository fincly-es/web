# Web pública de Fincly

Web estática de [fincly.app](https://fincly.app), publicada con Cloudflare Pages desde la rama `main`.

- `index.html`: landing con el formulario de alta de despachos (envía a HubSpot, centro de datos UE).
- `privacidad.html` y `aviso-legal.html`: páginas legales. **Rellenar los campos entre corchetes antes de fusionar a main.**
- `assets/`: tipografía Inter alojada en la propia web (sin Google Fonts) y fotos.

Cada PR genera una vista previa en Cloudflare Pages. Épica en Jira: FIN-5.
